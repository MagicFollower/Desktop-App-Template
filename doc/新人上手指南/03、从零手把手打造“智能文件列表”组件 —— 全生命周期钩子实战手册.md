### 1.2 组件怎么"说话"？（即 Props 通信协议）

这个组件不是"自闭症患者"，它需要跟父组件（使用它的地方）对话。我们把这种对话定义为 **"钩子（Hooks/Callbacks）"**。

| 钩子名称 | 触发时机（什么时候触发？） | 携带的数据（给父组件报告什么？） | 翻译成大白话 |
| :--- | :--- | :--- | :--- |
| **`onLoad`** | 组件**初次登场（挂载）** 时 | 无（它负责去拿数据） | "爸，我刚被造出来，我该显示哪些文件？" |
| **`onAdd`** | 用户点击"确认添加"按钮时 | `{ name, size, type }`（新文件信息） | "爸，用户想加一个新文件，这是数据，你存一下，并告诉我新文件的完整信息（包括 ID）" |
| **`onDelete`** | 用户点击某行的"删除"按钮时 | **`(id, fullItem)`**（被删文件的 ID + 完整信息） | "爸，用户把 ID 为 xxx 的文件删了！顺便给你看一眼这文件的全部资料，方便你记录日志或撤销！" |
| **`onError`** | 加载或操作失败时 | `(error)`（错误信息） | "爸，出事了（网络断了），这是报错内容！" |

> **新人大脑翻译官：** 
> "钩子"（Callback）就是**"预埋的电话线"**。我在组件内部挖好一个插座（定义 `onDelete`），当用户点击删除时，我不自己做主，而是**拿起电话（调用 `onDelete`），把信息（ID和数据）大声念给电话那头的父组件听**。至于父组件是要删除数据库、写日志、还是弹窗，都由它决定，我只负责"精准传递消息"。

## 第二章：环境搭建 —— 新建文件与基础类型定义

先别急着写 UI。**在 TypeScript 里，我们永远先定"合同"（类型），再盖"房子"（组件）。** 这样你写代码时，编辑器会自动帮你检查错误，就像有了一个 24 小时在线的语法老师。

### 步骤 1：定义文件对象的数据结构（`FileItem`）

在 `src/renderer/components/FileList.tsx` 中输入：

```tsx
// ==========================================
// 1. 导入依赖（进货）
// ==========================================
import React, { useState, useEffect, useCallback } from 'react';
// 解释：useCallback 用来"稳定"我们的钩子函数，防止组件无限重渲染（请回忆第10章）。

// ==========================================
// 2. 定义"文件"的合同（Interface）
//    这份合同规定了"文件"长什么样。
// ==========================================
export interface FileItem {
  id: string;          // 唯一身份证（必需）
  name: string;        // 文件名（必需）
  size: number;        // 文件大小（字节）（必需）
  modified: string;    // 修改日期（必需）
  type: 'folder' | 'file' | 'image' | 'video'; // 类型（用于显示图标）
  icon?: string;       // 可选：自定义图标（如果没有，我们根据 type 自动生成）
}

// ==========================================
// 3. 定义"组件的Props合同"（组件收到什么数据？）
//    这是整个组件的"使用说明书"！
// ==========================================
export interface FileListProps {
  // ---- 数据注入（可控/受控模式） ----
  data?: FileItem[];           // 外部传入的数据（如果传了，组件就用这份数据）
  loading?: boolean;           // 外部控制加载状态
  
  // ---- ★★★ 生命周期钩子（核心！） ★★★ ----
  // 加载钩子：返回 Promise，组件挂载时自动执行
  onLoad?: () => Promise<FileItem[]>;
  
  // 添加钩子：接收新文件信息（不含 id），返回完整的 FileItem（包含服务端生成的 id）
  onAdd?: (newItem: Omit<FileItem, 'id'>) => Promise<FileItem>;
  //                ^^^^^^^^^^^^^^^^^^^^^^ 
  //                解释：Omit<FileItem, 'id'> 意思是"去掉 id 字段"，
  //                因为添加时 id 是后端生成的，前端还没 id。
  
  // ★★★ 删除钩子（重点！精准记录） ★★★
  // 参数1: 被删文件的 id (string)
  // 参数2: 被删文件的 完整信息 (FileItem) —— 这就是"精准记录"！
  onDelete?: (id: string, deletedItem: FileItem) => Promise<void>;
  //            ^^^^^^^^  ^^^^^^^^^^^^^^^^^^^^^
  //            方便快速定位  方便记录日志/撤销
  
  // 错误钩子
  onError?: (error: Error) => void;
}
```

> **新人硬核拆解 `Omit<FileItem, 'id'>`：**
> 这是 TypeScript 的工具类型。`Omit` 是"省略"的意思。`Omit<FileItem, 'id'>` 就是"复制一份 FileItem 的合同，但是把 `id` 那一行撕掉"。因为用户在添加文件时，只需要填 `name` 和 `size`，`id` 是服务器或父组件生成的，不需要用户填。

## 第三章：组件内部地基 —— State（内存）与默认值

现在，我们来写组件本身。组件内部需要有个"小黑板"（State）来记录当前显示的文件列表，以及加载状态。

### 步骤 2：组件骨架与内部状态

```tsx
// ==========================================
// 4. 定义组件（积木制造机）
// ==========================================
function FileList(props: FileListProps) {
  // 4.1 解构 Props（从快递包裹里拿东西）
  const {
    data: externalData,      // 外部传入的数据（父组件给的）
    loading: externalLoading, // 外部传入的加载状态
    onLoad,                  // 加载钩子
    onAdd,                   // 添加钩子
    onDelete,                // 删除钩子（核心）
    onError,                 // 错误钩子
  } = props;

  // 4.2 内部状态（本组件的"记忆硬盘"）
  // 状态1：内部文件列表（如果没有外部数据，自己存一份）
  const [internalItems, setInternalItems] = useState<FileItem[]>([]);
  // 状态2：内部加载状态（如果没有外部控制，自己控制）
  const [internalLoading, setInternalLoading] = useState<boolean>(false);
  // 状态3：添加表单的输入值（用户正在输入的文字）
  const [newFileName, setNewFileName] = useState<string>('');
  const [newFileSize, setNewFileSize] = useState<string>(''); // 存字符串方便输入

  // 4.3 决定使用"外部数据"还是"内部数据"（受控/非受控模式）
  // 如果父组件传了 data，就用父组件的；否则用自己的。
  const items = externalData !== undefined ? externalData : internalItems;
  const loading = externalLoading !== undefined ? externalLoading : internalLoading;

  // 4.4 辅助函数：获取文件图标
  const getFileIcon = (item: FileItem): string => {
    if (item.icon) return item.icon; // 自定义优先
    switch (item.type) {
      case 'folder': return '📁';
      case 'image': return '🖼️';
      case 'video': return '🎬';
      default: return '📄';
    }
  };

  // 4.5 辅助函数：格式化文件大小（字节 -> KB/MB）
  const formatSize = (bytes: number): string => {
    if (bytes < 1024) return bytes + ' B';
    if (bytes < 1048576) return (bytes / 1024).toFixed(1) + ' KB';
    return (bytes / 1048576).toFixed(1) + ' MB';
  };

  // ... 后续逻辑和 JSX 渲染
}

export default FileList;
```

> **新人问答：**
> Q: 为什么要有 `externalData` 和 `internalItems` 两个？
> A: 这叫"受控/非受控模式"。
> - 如果父组件说"我来管数据"（传了 `data`），组件就是个"听话的展示器"（受控）。
> - 如果父组件说"你自己管数据"（没传 `data`），组件就自己存一份（非受控，适合简单场景）。
> 我们两个都支持，这样组件更灵活，就像遥控器既可以手动按键，也可以声控。

## 第四章：生命周期钩子的实现 —— 加载（`onLoad`）

这是组件"出生"（挂载）时要干的第一件事。我们用 `useEffect` 来实现。

### 步骤 3：实现"加载"钩子

```tsx
  // ==========================================
  // 5. 生命周期：挂载时加载数据（onLoad 钩子）
  // ==========================================
  useEffect(() => {
    // 如果外部控制了数据，就不执行内部加载
    if (externalData !== undefined) return;

    // 如果父组件没有提供 onLoad 钩子，就不加载
    if (!onLoad) return;

    // 定义异步加载函数
    const fetchData = async () => {
      try {
        setInternalLoading(true); // 显示"加载中..."
        const result = await onLoad(); // 调用父组件的钩子，拿到数据
        setInternalItems(result); // 存入内部状态
        setInternalLoading(false);
      } catch (error) {
        setInternalLoading(false);
        // 如果有错误钩子，报告错误
        if (onError) {
          onError(error instanceof Error ? error : new Error(String(error)));
        }
        console.error('❌ 文件加载失败:', error);
      }
    };

    fetchData();
  }, [onLoad, externalData, onError]); 
  // 依赖项：如果 onLoad 函数变了（比如父组件重新创建了），重新执行。
  // 但使用 useCallback 可以稳定 onLoad（见后面使用示例）。
```

> **新人硬核拆解 `async/await`：**
> - `async` 标记的函数：意思是我这个函数内部有"等待"操作。
> - `await onLoad()`：意思是"我在这里等着，等 `onLoad()` 这个 Promise 执行完（数据从服务器回来了），再把结果赋值给 `result`"。这就像点外卖，`await` 就是等待外卖员敲门，敲了门我才继续做饭。

## 第五章：删除钩子的实现 —— 精准记录信息（`onDelete`）

这是本组件的**核心亮点**。我们要确保点击删除时，不仅传 `id`，还要把整行数据都传过去，以便父组件"精准记录"。

### 步骤 4：实现"删除"钩子（带精准信息）

```tsx
  // ==========================================
  // 6. 删除操作（触发 onDelete 钩子）
  // ==========================================
  const handleDelete = useCallback(
    async (item: FileItem) => {
      // 6.1 安全检查：如果没提供 onDelete 钩子，就不执行
      if (!onDelete) {
        console.warn('⚠️ 未提供 onDelete 钩子，无法删除');
        return;
      }

      // 6.2 二次确认（良好的用户体验）
      const confirmDelete = window.confirm(
        `确定要删除文件 "${item.name}" 吗？此操作不可撤销！`
      );
      if (!confirmDelete) return;

      try {
        // 6.3 ★★★ 关键一步：调用 onDelete 钩子，精准传递信息 ★★★
        //     传递 1: item.id （快速定位）
        //     传递 2: item （完整的文件信息，方便记录日志）
        await onDelete(item.id, item);
        
        // 6.4 删除成功后，更新内部列表（如果是非受控模式）
        //    过滤掉被删除的那一项
        if (externalData === undefined) {
          setInternalItems(prevItems => 
            prevItems.filter(existingItem => existingItem.id !== item.id)
          );
        }
        
        console.log(`✅ 已删除文件: ${item.name} (ID: ${item.id})`);
      } catch (error) {
        // 删除失败，报告错误
        if (onError) {
          onError(error instanceof Error ? error : new Error(String(error)));
        }
        console.error(`❌ 删除文件 ${item.name} 失败:`, error);
      }
    },
    [onDelete, onError, externalData] // 依赖项
  );
```

> **"精准记录"的含金量：**
> 想象一下，如果你只传 `id`，父组件想记录日志："用户删除了文件，叫什么名字来着？"——父组件还得去数据库重新查一遍，多麻烦。
> 现在我们直接传 `item`，父组件可以立即打印日志：
> `console.log(${new Date().toISOString()} 用户删除了文件 ${item.name}，大小 ${item.size} 字节，类型 ${item.type});`
> 这就是"精准记录"的意义——**一次传递，信息齐全，无需二次查询**。

## 第六章：添加钩子的实现 —— 新增文件

### 步骤 5：实现"添加"钩子（`onAdd`）

```tsx
  // ==========================================
  // 7. 添加操作（触发 onAdd 钩子）
  // ==========================================
  const handleAdd = useCallback(async () => {
    // 7.1 校验输入
    const trimmedName = newFileName.trim();
    if (!trimmedName) {
      alert('请输入文件名');
      return;
    }
    const sizeNum = parseFloat(newFileSize);
    if (isNaN(sizeNum) || sizeNum < 0) {
      alert('请输入有效的大小（数字）');
      return;
    }

    // 7.2 如果没有提供 onAdd 钩子，只做本地添加（演示模式）
    if (!onAdd) {
      // 仅本地添加（纯前端演示）
      const fakeNewItem: FileItem = {
        id: `local-${Date.now()}`,
        name: trimmedName,
        size: sizeNum,
        modified: new Date().toLocaleString(),
        type: 'file',
      };
      if (externalData === undefined) {
        setInternalItems(prev => [fakeNewItem, ...prev]);
      }
      setNewFileName('');
      setNewFileSize('');
      return;
    }

    // 7.3 调用父组件的 onAdd 钩子
    try {
      const newItemData: Omit<FileItem, 'id'> = {
        name: trimmedName,
        size: sizeNum,
        modified: new Date().toLocaleString(),
        type: 'file',
      };
      
      const createdItem = await onAdd(newItemData); // 父组件返回带 ID 的完整对象
      
      // 7.4 添加成功后，更新列表（非受控模式）
      if (externalData === undefined) {
        setInternalItems(prev => [createdItem, ...prev]);
      }
      
      // 清空输入框
      setNewFileName('');
      setNewFileSize('');
      console.log(`✅ 已添加文件: ${createdItem.name} (ID: ${createdItem.id})`);
    } catch (error) {
      if (onError) {
        onError(error instanceof Error ? error : new Error(String(error)));
      }
      console.error('❌ 添加文件失败:', error);
    }
  }, [newFileName, newFileSize, onAdd, onError, externalData]);
```

## 第八章：完整组件代码（汇总）

为了方便你对照，我把上面所有碎片拼成完整的 `FileList.tsx`。你可以直接复制使用。

```tsx
// FileList.tsx
import React, { useState, useEffect, useCallback } from 'react';

// --- 类型定义 ---
export interface FileItem {
  id: string;
  name: string;
  size: number;
  modified: string;
  type: 'folder' | 'file' | 'image' | 'video';
  icon?: string;
}

export interface FileListProps {
  data?: FileItem[];
  loading?: boolean;
  onLoad?: () => Promise<FileItem[]>;
  onAdd?: (newItem: Omit<FileItem, 'id'>) => Promise<FileItem>;
  onDelete?: (id: string, deletedItem: FileItem) => Promise<void>; // ★ 精准双参
  onError?: (error: Error) => void;
}

// --- 组件 ---
function FileList(props: FileListProps) {
  const { data: externalData, loading: externalLoading, onLoad, onAdd, onDelete, onError } = props;

  const [internalItems, setInternalItems] = useState<FileItem[]>([]);
  const [internalLoading, setInternalLoading] = useState<boolean>(false);
  const [newFileName, setNewFileName] = useState<string>('');
  const [newFileSize, setNewFileSize] = useState<string>('');

  const items = externalData !== undefined ? externalData : internalItems;
  const loading = externalLoading !== undefined ? externalLoading : internalLoading;

  const getFileIcon = (item: FileItem): string => {
    if (item.icon) return item.icon;
    switch (item.type) {
      case 'folder': return '📁';
      case 'image': return '🖼️';
      case 'video': return '🎬';
      default: return '📄';
    }
  };

  const formatSize = (bytes: number): string => {
    if (bytes < 1024) return bytes + ' B';
    if (bytes < 1048576) return (bytes / 1024).toFixed(1) + ' KB';
    return (bytes / 1048576).toFixed(1) + ' MB';
  };

  // --- 加载钩子实现 ---
  useEffect(() => {
    if (externalData !== undefined) return;
    if (!onLoad) return;

    const fetchData = async () => {
      try {
        setInternalLoading(true);
        const result = await onLoad();
        setInternalItems(result);
        setInternalLoading(false);
      } catch (error) {
        setInternalLoading(false);
        if (onError) onError(error instanceof Error ? error : new Error(String(error)));
        console.error('加载失败:', error);
      }
    };
    fetchData();
  }, [onLoad, externalData, onError]);

  // --- 删除钩子实现（核心精准传递） ---
  const handleDelete = useCallback(async (item: FileItem) => {
    if (!onDelete) {
      console.warn('未提供 onDelete 钩子');
      return;
    }
    if (!window.confirm(`确定要删除 "${item.name}" 吗？`)) return;

    try {
      // ★ 调用时传入 (id, 完整对象)
      await onDelete(item.id, item);
      if (externalData === undefined) {
        setInternalItems(prev => prev.filter(existing => existing.id !== item.id));
      }
      console.log(`✅ 已精准删除: ${item.name} (ID: ${item.id})`);
    } catch (error) {
      if (onError) onError(error instanceof Error ? error : new Error(String(error)));
      console.error('删除失败:', error);
    }
  }, [onDelete, onError, externalData]);

  // --- 添加钩子实现 ---
  const handleAdd = useCallback(async () => {
    const trimmedName = newFileName.trim();
    if (!trimmedName) { alert('请输入文件名'); return; }
    const sizeNum = parseFloat(newFileSize);
    if (isNaN(sizeNum) || sizeNum < 0) { alert('请输入有效大小'); return; }

    if (!onAdd) {
      const fake: FileItem = {
        id: `local-${Date.now()}`,
        name: trimmedName,
        size: sizeNum,
        modified: new Date().toLocaleString(),
        type: 'file',
      };
      if (externalData === undefined) setInternalItems(prev => [fake, ...prev]);
      setNewFileName('');
      setNewFileSize('');
      return;
    }

    try {
      const newItemData: Omit<FileItem, 'id'> = {
        name: trimmedName,
        size: sizeNum,
        modified: new Date().toLocaleString(),
        type: 'file',
      };
      const created = await onAdd(newItemData);
      if (externalData === undefined) setInternalItems(prev => [created, ...prev]);
      setNewFileName('');
      setNewFileSize('');
      console.log(`✅ 已添加: ${created.name}`);
    } catch (error) {
      if (onError) onError(error instanceof Error ? error : new Error(String(error)));
      console.error('添加失败:', error);
    }
  }, [newFileName, newFileSize, onAdd, onError, externalData]);

  // --- JSX 渲染（精简样式，专注逻辑） ---
  return (
    <div style={{ padding: '20px', fontFamily: 'sans-serif' }}>
      <div style={{ display: 'flex', justifyContent: 'space-between', alignItems: 'center', marginBottom: '16px' }}>
        <h2 style={{ margin: 0 }}>📁 我的文件库</h2>
        {onLoad && <button onClick={() => window.location.reload()} disabled={loading}>🔄 刷新</button>}
      </div>

      {loading && <div>⏳ 加载中...</div>}

      {!loading && (
        <table style={{ width: '100%', borderCollapse: 'collapse', border: '1px solid #ddd' }}>
          <thead style={{ backgroundColor: '#f5f5f5' }}>
            <tr>
              <th style={{ padding: '10px', textAlign: 'left' }}>文件名</th>
              <th style={{ padding: '10px', textAlign: 'left' }}>大小</th>
              <th style={{ padding: '10px', textAlign: 'left' }}>修改日期</th>
              <th style={{ padding: '10px', textAlign: 'center' }}>操作</th>
            </tr>
          </thead>
          <tbody>
            {items.length === 0 ? (
              <tr><td colSpan={4} style={{ textAlign: 'center', padding: '40px', color: '#aaa' }}>📭 暂无文件</td></tr>
            ) : (
              items.map(item => (
                <tr key={item.id} style={{ borderBottom: '1px solid #eee' }}>
                  <td style={{ padding: '10px' }}><span style={{ marginRight: '8px' }}>{getFileIcon(item)}</span>{item.name}</td>
                  <td style={{ padding: '10px' }}>{item.type === 'folder' ? '-' : formatSize(item.size)}</td>
                  <td style={{ padding: '10px' }}>{item.modified}</td>
                  <td style={{ padding: '10px', textAlign: 'center' }}>
                    <button onClick={() => handleDelete(item)} disabled={loading} style={{ padding: '4px 12px', backgroundColor: '#ff4d4f', color: 'white', border: 'none', borderRadius: '4px', cursor: 'pointer' }}>🗑️ 删除</button>
                  </td>
                </tr>
              ))
            )}
          </tbody>
        </table>
      )}

      <div style={{ marginTop: '20px', display: 'flex', gap: '12px', alignItems: 'center', flexWrap: 'wrap' }}>
        <span>➕ 添加文件：</span>
        <input type="text" placeholder="文件名" value={newFileName} onChange={(e) => setNewFileName(e.target.value)} style={{ padding: '6px 12px', border: '1px solid #ccc', borderRadius: '4px' }} />
        <input type="number" placeholder="大小 (字节)" value={newFileSize} onChange={(e) => setNewFileSize(e.target.value)} style={{ padding: '6px 12px', border: '1px solid #ccc', borderRadius: '4px', width: '140px' }} />
        <button onClick={handleAdd} disabled={loading} style={{ padding: '6px 20px', backgroundColor: '#1890ff', color: 'white', border: 'none', borderRadius: '4px', cursor: 'pointer' }}>📥 确认添加</button>
      </div>
    </div>
  );
}

export default FileList;
```

## 第九章：如何使用 —— 父组件（App.tsx）实战演示

组件造好了，怎么用？我们模拟一个父组件，展示如何利用这些"钩子"。

```tsx
// App.tsx (使用 FileList 的示例)
import React, { useCallback, useState } from 'react';
import FileList, { FileItem } from './components/FileList';

function App() {
  // 模拟服务端数据
  const [serverData, setServerData] = useState<FileItem[]>([

    { id: '2', name: '数据.xlsx', size: 1153433, modified: '2026-09-04', type: 'file' },
  ]);

  // ★ 1. 实现 onLoad 钩子（模拟异步请求）
  const handleLoad = useCallback(async (): Promise<FileItem[]> => {
    console.log('⏳ [钩子] 正在加载数据...');

    await new Promise(resolve => setTimeout(resolve, 800));

    ];
  }, []);

  // ★ 2. 实现 onAdd 钩子（模拟服务端生成 ID）
  const handleAdd = useCallback(async (newItem: Omit<FileItem, 'id'>): Promise<FileItem> => {
    console.log('📝 [钩子] 正在添加文件:', newItem.name);
    await new Promise(resolve => setTimeout(resolve, 500));
    const created: FileItem = {
      ...newItem,
      id: `server-${Date.now()}`, // 模拟服务端生成唯一 ID
    };

    return created;

    // setServerData(prev => prev.filter(item => item.id !== id));
  }, []);

      <FileList

          console.log('受控删除:', item.name);
          setServerData(prev => prev.filter(i => i.id !== id));
        }}
      />
    </div>
  );
}
```

## 第十章：生命周期与钩子对应表（查字典）

为了让你在写代码时快速定位"某个阶段该用哪个钩子"，我做了一张总表：

| 阶段 | 对应代码位置 | 钩子/函数 | 传递的数据 | 翻译 |
| :--- | :--- | :--- | :--- | :--- |
| **组件诞生（挂载）** | `useEffect` + `onLoad` | `onLoad` | 无 → 返回 `FileItem[]` | "刚插上电，去拿初始数据。" |
| **用户点击添加** | `handleAdd` | `onAdd` | `{ name, size }` → 返回完整 `FileItem` | "用户填了表单，你去存一下，并把新 ID 告诉我。" |
| **用户点击删除** | `handleDelete` | `onDelete` | **(id, fullItem)** → `Promise<void>` | "用户要删这个。ID 给你，它的全部资料也打包给你，方便你写日志/做撤销。" |
| **操作失败** | `catch` 块 | `onError` | `(Error)` | "出错了，这是错误详情，你看着处理（弹窗或上报）。" |
| **数据变化（更新）** | `useEffect` 依赖项 | 内部 `setInternalItems` | 新数据数组 | "列表变了，重新画表格。" |
| **组件销毁** | `useEffect` 清理函数 | (可选) | 清理定时器/取消请求 | "组件要卸了，把残留的定时器/请求关掉。" |

## 第十一章：新人的"避坑指南"（血泪经验）

1.  **永远不要直接修改 State（`items.push` 是大忌！）**
   - ❌ 错误：`items.push(newItem); setItems(items);`
   - ✅ 正确：`setItems(prev => [...prev, newItem]);`
   - 原因：React 依赖不可变数据来检测变化。直接修改原数组，React 不知道变了，不会重新渲染。

2.  **`useCallback` 的依赖项一定要填对**
   - 如果 `handleDelete` 里用了 `onDelete` 和 `onError`，但依赖数组里忘了写，你的 `handleDelete` 会一直使用"旧的、过时的"钩子函数。
   - **口诀**：用了什么外部变量，就把它写进依赖数组 `[]` 里。

3.  **`onDelete` 传 `item` 会不会泄露隐私？**
   - 不会。这是在内存中传递 JavaScript 对象，只有父组件能收到。而且正是为了"精准记录日志"（比如审计合规要求），我们才需要完整信息。

4.  **如果没有提供 `onDelete` 钩子，删除按钮该不该显示？**
   - 在《第七章》的渲染中，无论有没有 `onDelete`，我都显示了删除按钮。但在 `handleDelete` 里，我做了 `if (!onDelete) return;` 的安全判断。这样按钮显示，但点了没反应并打印警告。更好的做法是：**如果没传 `onDelete`，干脆隐藏删除按钮**，这留给新手作为练习题。
